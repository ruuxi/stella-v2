# Legacy test assertion coverage map

This map records the disposition of the eleven tests removed while local chat,
memory, Dream, and device-presence behavior moved to the final Effect + cloud
architecture. A deleted test is not treated as covered merely because a new
test has a similar name: the replacement column names the current assertion
surface, or the restoration column records the assertion added in this pass.
