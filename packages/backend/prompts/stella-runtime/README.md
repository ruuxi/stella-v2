# Stella backend-only prompt sources

This directory does not own the active bundled runtime prompt roster. The
authoritative sources for those prompts are:

- `packages/runtime/extensions/stella-runtime/agent-metadata/*.md` for agent
  capability frontmatter and prompt bodies;
- `packages/runtime/extensions/stella-runtime/prompts/*.md` for non-agent
  prompt bodies.

The backend generator reads those runtime-owned files, strips agent
frontmatter, and produces the checked-in Convex fallback snapshot. It rejects
any duplicate active-roster source under this directory so ownership cannot
silently reverse again.

Backend Markdown belongs here only when a prompt is genuinely cloud- or
background-only and has no bundled runtime representation. There are no such
prompts in the current ten-entry publication roster, so this README is the only
source file in this directory.

Only the current orchestrated runtime is represented. The manifest has one
`agents/orchestrator.md` entry and no compatibility entries for the retired
direct orchestrator, `orchestrator-orchestrated`, Manager, Schedule, Dream, or
install-update agents.

Run `bun run prompts:sync-defaults` from `packages/backend` to regenerate the
checked-in snapshot. Run `bun run prompts:check-defaults` to fail when runtime
sources, contracts, ownership, or generated bytes drift.
