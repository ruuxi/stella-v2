# Legacy test assertion coverage map

This map records the disposition of the eleven tests removed while local chat,
memory, and device-presence behavior moved to the final Effect + cloud
architecture. A deleted test is not treated as covered merely because a new
test has a similar name: the replacement column names the current assertion
surface, or the restoration column records the assertion added in this pass.

Automatic memory review has since been retired everywhere rather than rebuilt in
the cloud. The five rows below that once pointed at a cloud Dream replacement now
name the coverage that pins the retirement itself, plus the surviving surfaces:
explicit `Remember` writes, `Recall` search, and the thread summaries and memory
documents Recall still reads.
